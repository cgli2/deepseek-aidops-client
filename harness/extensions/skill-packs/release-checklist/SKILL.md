# 发布检查清单

version: 1.1

面向版本发布/上线场景的技能包示例：演示「一个文件夹 = 一个技能单元」的导入方式。
整个 `release-checklist/` 目录可经设置 → 技能管理 →「导入技能包（文件夹）」批量导入。

## 触发边界

发布新版本、上线部署、打包交付，或用户要求执行发布检查清单

## 执行步骤

- 运行受影响模块的全部测试并记录结果
- 核对版本号、变更日志与发布说明一致
- 按 resources/checklist-template.md 逐项确认发布前置条件
- 产出发布检查报告（通过项 / 阻塞项 / 风险项）

## 验证规则

- 测试全部通过且有结果记录
- 检查清单每一项都有结论
- 阻塞项已给出原因与处理建议
