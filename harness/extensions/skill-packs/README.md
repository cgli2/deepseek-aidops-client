# 技能包（Skill Pack）示例

本目录提供两个可直接导入的技能包示例，演示标准的「技能包」规范：

```
skill-packs/
├── release-checklist/          ← 一个技能包 = 一个文件夹
│   ├── SKILL.md                ← 必需：技能入口（触发边界 / 执行步骤 / 验证规则）
│   └── resources/              ← 可选：资源文件（登记进 Skill.resource_files）
│       └── checklist-template.md
└── sql-review/
    └── SKILL.md
```

## 导入方式

AIOPS Desktop → 设置 → 技能管理 →「导入技能包（文件夹）」，选择本目录：
系统会递归扫描所有含 `SKILL.md` 的目录，每个目录作为一个独立技能单元
**复制进约定目录** `<workspace>/.harness-memory/skills/<包名>/`；也可以
直接把包目录手动拷进该约定目录，下次启动 Agent 会自动扫描加载。
新加载的技能包默认未启用，需在面板勾选后才参与匹配。

## SKILL.md 规范

- `# 标题`：技能名称；
- 头部块（第一个 `##` 之前）可选 `version: x.y` 声明版本（也支持 `版本：`）；
- `## 触发边界`：何时应用该技能（`match_skills` 依据它与用户输入做词法匹配）；
- `## 执行步骤`：有序步骤列表；
- `## 验证规则`：执行后用于校验成果的规则。

## 幂等语义

技能包身份 = 约定目录下的子目录名（id 形如 `pack:<目录名>`），与来源路径无关：
重复导入同一文件夹只会**整体替换更新**已有包（保留你在面板里设置的启用/禁用
状态），不会产生副本；在面板删除技能时包子目录一并回收。

完整设计见 `docs/skill-module-redesign.md`。
